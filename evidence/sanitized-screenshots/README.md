# evidence/sanitized-screenshots — historical material

These seven PNGs are the **historical April-2026 screenshots** from the original lab
record (source commit `43a7141c`, previously under `docs/evidence/`). Their
SHA-256 values are in `manifest.json`.

They are **not run evidence**: they carry no run id, no `es_id`, no `@timestamp` and
were never verified against this repository's acceptance verifier. They remain here
for provenance of the earlier analysis documents (`../docs/case-study.md`,
`../docs/attack-detection-mapping.md`). Any claim about a run derives from the run
ledgers under `runs/`, not from these files.
